in the right browser.

Link Router takes the place of your default browser on macOS. A click either goes straight to the browser or Chrome profile a rule picks, or brings up a small picker: type two letters, press ↵.

curl -fsSL https://raw.githubusercontent.com/macrosak/link-router/main/install.sh | bash

or download the DMG · macOS 13+, Apple silicon · free and MIT-licensed

Rules that know where you clicked.

A rule can look at the URL, the app the link came from, and that app's window title. IDEs put the project name in the title, so every IntelliJ project window can open its links in its own Chrome profile.

The first matching rule opens the link directly. Nothing matches? You get the picker. Hold ⌥ while clicking to get it anyway.

Other link pickers launch a second copy of the browser just to pass it a URL and a profile. Link Router writes the request straight into the socket the running browser already listens on, the same way Chrome's own second instance would. Chrome, Brave, Edge, Vivaldi and Chromium work this way; every other browser opens normally.

Install

  1. Run this in Terminal. It installs the latest release (or updates it) and launches it.

    curl -fsSL https://raw.githubusercontent.com/macrosak/link-router/main/install.sh | bash

  2. Say yes when it offers to become your default browser. macOS asks you to confirm.

  3. Optional: for window-title rules, grant Accessibility in Settings → General, then relaunch. Releases share one signing identity, so the grant survives updates.

Prefer the DMG? Get it from Releases, drag the app to Applications and run xattr -dr com.apple.quarantine "/Applications/Link Router.app" once, since the builds aren't notarized. The README covers building from source and troubleshooting.
